# BlinkObserverTool 利用者向けインストーラー導入マニュアル

本書は、ゲーム画面の瞬き（まばたき）を画像認識で検出し、指定したウィンドウへキー入力を自動送信する観測補助ツール「BlinkObserverTool」の利用者向け導入・運用マニュアルです。

Windows インストーラー（Microsoft Windows Installer: MSI）形式パッケージの入手から、初期導入、更新、アンインストール、設定・プロファイルの保護仕様、物理入力ドライバの個別導入手順、トラブルシューティングまでを詳しく説明します。

> **開発者・運用者の方へ:**  
> MSI パッケージのビルド手順、CI/CD（継続的インテグレーション／継続的デリバリー）ワークフロー、GitHub Releases への発行手順など、開発・リリース運用に関する技術仕様は [BlinkObserverTool 開発者・運用者向けリリース運用マニュアル](developer-release-manual.ja.md) を参照してください。

## 1. 動作環境

BlinkObserverTool を使用するために必要な環境は以下のとおりです。

| 項目 | 要件 | 補足 |
|---|---|---|
| オペレーティング システム (OS: Operating System) | 64ビット版 Windows 10 または Windows 11 (x64) | 32ビット版 (x86) や ARM 版 Windows には対応していません。 |
| .NET ランタイム | 事前インストール不要 | 本製品は自己完結型（Self-Contained）形式で構築されているため、必要な .NET 10 ランタイム一式が同梱されています。 |
| 映像入力デバイス | Webカメラまたは HDMI キャプチャ デバイス | 画面認識を行うため、DirectShow 対応のキャプチャ機器（HDMI: High-Definition Multimedia Interface 接続等）が必要です（推奨解像度: 1280x720）。 |
| 権限 | 標準ユーザー権限（インストール時）<br>管理者権限（物理入力ドライバ導入時のみ） | アプリケーション本体は一般ユーザー権限のみでインストール可能です（ユーザー アカウント制御: UAC による管理者昇格は不要です）。 |

## 2. インストーラーパッケージの入手

BlinkObserverTool は、GitHub（ソフトウェア開発・配布プラットフォーム）の公開リポジトリの「Releases（リリース）」ページから配布されています。

1. Webブラウザーで公式リポジトリの **Releases** ページを開きます。
2. **Latest**（最新版）と表記されたリリースタグ（例: `v1.2.3`）を確認します。
3. リリース内の **Assets**（配布物一覧）から、以下の2つのファイルをダウンロードして同じフォルダーに保存します。
   - `BlinkObserverTool.Installer.msi` （インストーラー本体）
   - `BlinkObserverTool.Installer.msi.sha256` （改ざん・破損確認用ハッシュファイル）

> **注意:**
> BlinkObserverTool の公式配布物は単一の MSI パッケージのみです。EXE（Executable: 実行可能ファイル）形式のインストーラーは配布されません。第三者サイト等から配布されている不審なファイルは使用しないでください。

## 3. インストール前確認（ハッシュ検証）

ダウンロード中にファイルが破損していないか、また改ざんされていないかを確認するために、SHA-256（Secure Hash Algorithm 256-bit: 暗号学的ハッシュ関数）を用いた検証を行うことを推奨します。

配布されている `.sha256` ファイルは、標準的なハッシュ検証形式（64 文字のハッシュ値、空白、ファイル名）で記述されています。

Windows に標準搭載されている **Windows PowerShell** を起動し、ダウンロードしたフォルダーに移動して以下のコマンドを実行します。

```powershell
Get-FileHash .\BlinkObserverTool.Installer.msi -Algorithm SHA256
```

また、同梱の `.sha256` ファイルと自動照合する場合は、以下のコマンドを実行します。

```powershell
(Get-FileHash .\BlinkObserverTool.Installer.msi -Algorithm SHA256).Hash -eq ((Get-Content .\BlinkObserverTool.Installer.msi.sha256) -split '\s+')[0]
```

実行結果として `True` が返されれば、ダウンロードした MSI パッケージが開発元の発行したファイルと完全に一致していることが確認できます。`False` と表示された場合はファイルが破損している可能性があるため、再度ダウンロードしてください。

## 4. 未署名パッケージに関する警告への対処

現行バージョンのインストーラーパッケージには、商用のコード署名証明書による電子署名がまだ設定されていません。そのため、MSI ファイルを実行した際に Windows Defender SmartScreen（スマートスクリーン: Windows のセキュリティ保護機能）によって警告画面が表示される場合があります。

### SmartScreen 警告が表示された場合の操作手順

1. 画面上に **「Windows によって PC が保護されました」** というダイアログが表示されます。
   - メッセージ: 「Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC に影響が及ぶ可能性があります。」
2. ダイアログ内の説明文にある **「詳細情報」** という下線付きのリンクをクリックします。
3. アプリ名（`BlinkObserverTool.Installer.msi`）と発行元（未確認）が表示され、右下に **「実行」** ボタンが現れます。
4. 前述の [3. インストール前確認（ハッシュ検証）](#3-インストール前確認ハッシュ検証) でハッシュ値が一致していることを確認した上で、**「実行」** ボタンをクリックしてください。

## 5. 初回インストール手順

BlinkObserverTool は、現在のログインユーザー専用にインストールされるユーザー別（per-user）インストールを採用しています。管理者パスワードの入力（UAC: ユーザー アカウント制御の昇格ダイアログ）を必要とせず、一般ユーザー権限のみで安全にインストールできます。

### インストール先フォルダー

プログラム本体は以下のユーザー領域に配置されます。

```text
%LOCALAPPDATA%\Programs\pokenae\BlinkTools\BlinkObserverTool
```
（例: `C:\Users\<ユーザー名>\AppData\Local\Programs\pokenae\BlinkTools\BlinkObserverTool`）

### グラフィカル ユーザー インターフェイス（GUI）での導入手順

1. ダウンロードした `BlinkObserverTool.Installer.msi` をダブルクリックして起動します。
2. インストールウィザードが開いたら **「次へ」** をクリックします。
3. **「カスタム セットアップ」** 画面が表示されます。以下の構成ツリーが表示されます。
   - **BlinkObserverTool** （本体機能: 必須）
   - **デスクトップショートカット** （デスクトップにショートカットアイコンを作成する機能）
   
   > **デスクトップショートカットの作成要否の切り替え:**
   > - デスクトップにショートカットを作成したい場合: そのまま「次へ」をクリックします（既定で有効です）。
   > - デスクトップ上にアイコンを作成したくない場合: 「デスクトップショートカット」項目の左端にあるアイコンをクリックし、表示されるメニューから **「この機能を使用できないようにします」**（環境によっては `Entire feature will be unavailable`）を選択します。
4. **「インストール」** をクリックするとファイルの配置が開始されます。
5. インストールが完了したら **「完了」** をクリックしてウィザードを閉じます。

### コマンドライン（PowerShell）でのサイレント導入手順

GUI 画面を表示せずにバックグラウンドで導入したい場合は、Windows PowerShell で以下を実行します。

```powershell
# 通常のサイレントインストール（デスクトップショートカット含む）
msiexec /i .\BlinkObserverTool.Installer.msi /qn

# デスクトップショートカットを除外して本体のみサイレントインストール
msiexec /i .\BlinkObserverTool.Installer.msi /qn ADDLOCAL=MainFeature
```

## 6. アプリケーションの起動

インストール完了後、以下のいずれかの方法で BlinkObserverTool を起動できます。

1. **スタートメニューから起動:**
   - Windows のスタートボタンをクリックし、「すべてのアプリ」一覧から **「pokenae」** > **「BlinkObserverTool」** フォルダー内の **「BlinkObserverTool」** を選択します。
2. **デスクトップショートカットから起動:**
   - インストール時にデスクトップショートカットを有効にした場合、デスクトップ上の **「BlinkObserverTool」** アイコンをダブルクリックします。
3. **PowerShell からの直接起動:**
   ```powershell
   & "$env:LOCALAPPDATA\Programs\pokenae\BlinkTools\BlinkObserverTool\BlinkObserverTool.exe"
   ```

## 7. 同梱プロファイルの自動同期とユーザープロファイルの保護

BlinkObserverTool には、導入直後から利用可能な暗所環境向けの検証済み認識プロファイルが同梱されています。

### 同梱される標準プロファイル

| プロファイル名 | 認識方式 | 特徴 |
|---|---|---|
| `暗所_2026-09-21_08-52-45_瞬き特徴` | 瞬き特徴認識 | 目の局所コントラストを正規化し、開眼状態からの時間変化で検出 |
| `暗所_2026-09-21_08-59-52_テンプレート` | テンプレートマッチング | 閉眼時の目元画像パターンとの一致度で検出 |

### データ保存領域と自動同期の仕組み

アプリケーションは起動時に、インストールフォルダー内の同梱定義を読み込み、ユーザーごとのローカル アプリケーション データ領域（`%LOCALAPPDATA%`）へ自動配置します。

- **ユーザーデータ領域:**
  ```text
  %LOCALAPPDATA%\pokenae\BlinkObserverTool
  ```
- **認識プロファイル格納フォルダー:**
  ```text
  %LOCALAPPDATA%\pokenae\BlinkObserverTool\Profiles
  ```
- **同期状態管理ファイル:**
  ```text
  %LOCALAPPDATA%\pokenae\BlinkObserverTool\default-profiles-state.json
  ```
- **キー送信設定保存ファイル:**
  ```text
  %LOCALAPPDATA%\pokenae\BlinkObserverTool\BlinkConfigs\blink-send-configurations.json
  ```

### ユーザーデータの保護ルール

ユーザーが作成・編集した設定は、以下の厳密なルールにより保護されます。

1. **新規作成プロファイルの完全保護:**
   利用者が独自に作成・保存したプロファイルは、同期処理によって変更・削除されることはありません。
2. **編集済みプロファイルの保護:**
   同梱プロファイルを基にパラメーターの調整や画像差し替え、ファイルの追加を行った場合、ハッシュ値の変化により「編集済み」と判定されます。将来のバージョンアップ時でも、利用者の編集済みプロファイルが上書きされることはありません。
3. **未編集プロファイルの安全な更新:**
   前回の配布時からユーザーが一度も手を加えていない同梱プロファイルのみ、最新版のプロファイル内容へ自動更新されます。
4. **画面上での反映:**
   起動後にメイン画面の「自動認識プロファイル」枠内にある **「一覧更新」** ボタンを押すと、最新のプロファイル一覧がコンボボックスに再読み込みされます。

## 8. メジャーアップグレード（新バージョンへの更新）

新しいバージョンがリリースされた場合、古いバージョンを事前にアンインストールする必要はありません。

1. GitHub Releases ページから最新バージョンの `BlinkObserverTool.Installer.msi` をダウンロードします。
2. ダウンロードした MSI ファイルを実行します。
3. Windows Installer のメジャーアップグレード機能（Major Upgrade: 旧版を自動削除して新版へ置き換える更新機能）が自動的に作動し、古いバージョンのプログラムファイルを安全に撤去した上で、新バージョンのファイルを配置します。
4. ユーザーデータフォルダー（`%LOCALAPPDATA%\pokenae\BlinkObserverTool`）内のプロファイルや保存済み設定は独立して保持されているため、更新によって消去されることはありません。

> 旧日付ベース版（例: `26.9.21.845`）が残っている環境でも、現行 SemVer 版の MSI は最初の 1 回だけその旧版を自動アンインストールしてから移行します。手動で旧版を削除しておく必要はありません。

## 9. ダウングレード拒否仕様（旧版への誤更新防止）

BlinkObserverTool のインストーラーには誤更新防止機能が備わっており、既存のバージョンよりも古いバージョン（または同じバージョン）のパッケージを誤って上書きインストールすることを防ぐよう構成されています。

### ダウングレード時の挙動

すでに新しいバージョンがインストールされている状態で旧バージョンの MSI を起動した場合、以下のエラーメッセージが表示されてインストールが自動的に中断されます。

```text
A newer version of BlinkObserverTool is already installed.
（新しいバージョンの BlinkObserverTool が既にインストールされています。）
```

### 旧バージョンへ戻したい場合の手順

意図して過去のバージョンに戻す必要がある場合は、以下の手順に従ってください。

1. 現在インストールされている新しいバージョンをアンインストールします（手順は [11. アンインストール手順](#11-アンインストール手順) を参照）。
2. アンインストール完了後、導入したい過去バージョンの `BlinkObserverTool.Installer.msi` を実行してインストールします。
3. ユーザープロファイルや設定データはアンインストール時にも保持されるため、旧バージョン起動後も引き継がれます。

## 10. 修復および再インストール手順

ファイルの誤削除やシステム異常などによりプログラムの一部が破損した場合、インストーラーの修復機能を利用して正常な状態に戻すことができます。

### Windows の設定画面から修復する場合

1. Windows の「スタート」ボタンを右クリックし、**「インストールされているアプリ」**（または「設定」>「アプリ」>「インストールされているアプリ」）を開きます。
2. アプリ一覧から **「BlinkObserverTool」** を探します。
3. 右端のメニュー（`...`）をクリックし、**「変更」** を選択します。
4. ウィザード画面で **「修復」** を選択して進めると、破損・欠落したファイルが自動的に再配置されます。

### コマンドライン（PowerShell）から修復する場合

現在インストールされているバージョンと同じバージョンの MSI ファイルがある場所で、以下を実行します。

```powershell
msiexec /f .\BlinkObserverTool.Installer.msi
```

## 11. アンインストール手順

### 通常のアンインストール手順

1. Windows の「スタート」ボタンを右クリックし、**「インストールされているアプリ」** を開きます。
2. アプリ一覧から **「BlinkObserverTool」** を見つけます。
3. 右端のメニュー（`...`）をクリックし、**「アンインストール」** を選択します。
4. 確認画面で **「アンインストール」** をクリックすると、自動的にプログラムが削除されます。

PowerShell からコマンドでアンインストールする場合は以下を実行します。

```powershell
msiexec /x .\BlinkObserverTool.Installer.msi
```

### 削除される項目と残る項目

| 項目 | 状態 | パス / 内容 |
|---|---|---|
| プログラム本体 | **削除されます** | `%LOCALAPPDATA%\Programs\pokenae\BlinkTools\BlinkObserverTool` |
| ショートカット | **削除されます** | スタートメニューおよびデスクトップ上のアイコン |
| インストーラー登録情報 | **削除されます** | レジストリ（`HKCU\Software\pokenae\BlinkObserverTool`、HKCU はログインユーザー専用の HKEY_CURRENT_USER） |
| **ユーザープロファイル** | **保持されます（削除されません）** | `%LOCALAPPDATA%\pokenae\BlinkObserverTool\Profiles` |
| **保存済み設定** | **保持されます（削除されません）** | `%LOCALAPPDATA%\pokenae\BlinkObserverTool\BlinkConfigs` |
| **同期状態記録** | **保持されます（削除されません）** | `%LOCALAPPDATA%\pokenae\BlinkObserverTool\default-profiles-state.json` |

> **すべてのデータを完全に削除したい場合:**
> 将来的な再利用の予定がなく、設定やプロファイルも含めて完全に削除したい場合は、アンインストール完了後に Windows PowerShell で以下のフォルダーを手動削除してください。
> ```powershell
> Remove-Item -Path "$env:LOCALAPPDATA\pokenae\BlinkObserverTool" -Recurse -Force
> ```

## 12. 物理入力ドライバ（InputInterceptor）の個別導入に関する注意事項

### 物理入力が必要となる背景

第7世代乱数調整支援ツール「7genBlinkSearch」などの一部の外部ソフトウェアは、Python の `pynput` ライブラリ等を用いて低水準でキー入力を監視しています。このようなツールに対しては、OS の通常の擬似入力送信 API（Application Programming Interface: `SendInput`）によるキー送信では認識されない場合があり、ハードウェアキーボードと同等の物理入力レベルでのキー信号送信が必要になります。

BlinkObserverTool では、これを実現するために **「物理入力(Interception)」** および **「物理入力(Interception長押し)」** の送信方式を備えています。

### なぜアプリ本体のインストーラーと分離されているのか

- **アプリ本体の安全性と手軽さの維持:**
  BlinkObserverTool 本体は、管理者権限不要で誰でも安全・簡単に導入できる per-user インストーラーを採用しています。
- **カーネルドライバの導入権限:**
  `InputInterceptor`（Interception）は Windows のカーネル層で動作するデバイス フィルタ ドライバです。この導入にはコンピューターの **システム管理者権限（Administrators 権限）** が必須となり、システムの再起動を伴う場合があります。
- そのため、セキュリティおよびインストーラーの安定性設計として、ドライバのセットアップはアプリ本体の MSI とは切り離し、必要なユーザーのみがアプリ内の専用機能から導入する構成となっています。

### 物理入力ドライバの導入手順

1. 一旦 BlinkObserverTool を終了します。
2. スタートメニューまたは実行ファイルを **右クリック** し、**「管理者として実行」** を選択して BlinkObserverTool を起動します。
   （※ 管理者権限で起動していない場合、ドライバ導入ボタンを押しても「InputInterceptor ドライバの導入には管理者権限が必要です。管理者として再実行してください。」というエラーメッセージが表示されます。）
3. メイン画面の「キー送信設定」枠内にある **「物理入力ドライバ導入」** ボタンをクリックします。
4. 導入完了メッセージが表示されたら、ボタン下部の **「ドライバ状態:」** 表示を確認します。
   - **「未導入」:** ドライバがまだインストールされていません。
   - **「導入済み(再起動待ち/デバイス未検出)」:** ドライバのインストールは完了しましたが、OS による認識が完了していません。**Windows を再起動してください。**
   - **「導入済み(送信準備前)」 / 「導入済み(物理キーボード入力待ち)」:** ドライバはロードされています。キーボードのキーを何か押すとデバイスが捕捉されます。
   - **「利用可能」:** 物理入力送信が正常に利用できる状態です。
5. ドライバが利用可能になったら、「送信方式」のドロップダウンから **「物理入力(Interception)」** または **「物理入力(Interception長押し)」** を選択してご使用ください。

## 13. トラブルシューティング

### Q1. アプリ起動時に「Blink Observer Startup Error」というエラーダイアログが表示される
- **原因:** ユーザーデータフォルダー（`%LOCALAPPDATA%\pokenae\BlinkObserverTool`）に対するアクセス権限が不足しているか、ディスク容量不足、またはセキュリティ対策ソフトによるフォルダーアクセスのブロックが考えられます。
- **対処:**
  1. `%LOCALAPPDATA%\pokenae\BlinkObserverTool` フォルダーが存在し、書き込み権限があるか確認します。
  2. セキュリティ対策ソフトの「保護されたフォルダー」機能などでアクセスが遮断されていないか確認します。

### Q2. カメラの映像が表示されない（プレビュー画面が暗転したままになる）
- **対処:**
  1. Windows の「設定」>「プライバシーとセキュリティ」>「カメラ」を開き、「アプリにカメラへのアクセスを許可する」および「デスクトップ アプリがカメラにアクセスできるようにする」が「オン」になっていることを確認します。
  2. 他のキャプチャソフトや配信ソフト（OBS Studio: Open Broadcaster Software など）が同じカメラデバイスを排他利用していないか確認します。
  3. 「自動認識プロファイル」枠の **「自動認識設定を開く」** から、カメラデバイス番号（Camera 0, 1, 2...）や解像度の設定がキャプチャ機器の仕様と一致しているか確認します。

### Q3. 瞬きを検知しても目的のツールにキーが送信されない
- **対処:**
  1. **「候補ウィンドウ」の反映:**
     「キー送信設定」エリアの **「候補更新」** をクリックし、ドロップダウンから送信先のツールウィンドウを選択して **「候補を反映」** をクリックします。手入力による「対象プロセス名」や「対象ウィンドウ名」のスペルミスを防ぐことができます。
  2. **前面化オプションの確認:**
     **「送信前に対象ウィンドウを前面化する」** のチェックボックスが「オン」になっていることを確認します。
  3. **送信テストの実施:**
     **「送信テスト」** ボタンをクリックし、送信先ツールにキーが正しく伝達されるか確認します。
  4. **送信方式の切り替え:**
     7genBlinkSearch 等を使用している場合、「送信方式」を `Auto (修飾キーはスキャンコード)` から **「物理入力(Interception)」** に切り替えてお試しください（事前に [12. 物理入力ドライバの個別導入](#12-物理入力ドライバinputinterceptorの個別導入に関する注意事項) を完了させておく必要があります）。

### Q4. 1回の瞬きでキーが何回も連打されてしまう
- **対処:**
  1. 「キー送信設定」枠内の **「瞬き集約時間(ms)」** の数値を調整します（標準値: `350` ms。これを `400`〜`500` ms 程度に増やすことで、瞬き動作中の連続検出を1回としてまとめます）。
  2. **「同一瞬きとしてまとめる回数」** が意図した値（通常は `1`）になっているか確認します。

### Q5. 実際のキー送信を行う前に、瞬きの検知精度だけをテストしたい
- **対処:**
  1. 「観測モード」枠で **「検証のみ (ログ / 通知音)」** のラジオボタンを選択します。
  2. **「検証時に瞬き検出音を鳴らす」** にチェックを入れます。
  3. **「観測開始」** をクリックします。キー送信は行われず、瞬きを検出するたびに指定した通知音が鳴り、画面右下の「本体ログ」に検出時刻（`瞬き検出: HH:mm:ss.fff`）が記録されます。

## 14. 問い合わせ時に収集・報告すべき診断情報

不具合の調査やサポートを依頼する際は、以下の情報を収集してご報告いただくと迅速な解決に役立ちます。

### 報告時に提供する基本情報

1. **BlinkObserverTool のバージョン:**
   - メイン画面のタイトルバーまたは MSI のバージョン（例: `v1.2.3`）。
2. **Windows のバージョンおよびビルド情報:**
   - Windows PowerShell で以下を実行して得られる文字列:
     ```powershell
     [System.Environment]::OSVersion.VersionString
     ```
3. **メイン画面の「本体ログ」の内容:**
   - メイン画面右下の「本体ログ」リストボックスに表示されているログ文字列（エラー内容や送信結果メッセージ）。
4. **「現在の設定」欄の表示内容:**
   - メイン画面右上の「現在の設定」に表示されている項目一覧（観測モード、認識プロファイル、送信キー、送信方式、対象プロセス等）。
5. **「ドライバ状態:」の表示内容:**
   - 物理入力ドライバを使用している場合、「ドライバ状態: 未導入」「利用可能」などの表示文字列。
6. **エラー発生時の正確なメッセージ:**
   - ポップアップ表示されたエラーダイアログのタイトルおよび本文テキスト（またはスクリーンショット）。

### 診断ファイルの取得場所

詳細な調査が必要な場合は、以下のファイルを添付してください。

| ファイル | パス | 内容 |
|---|---|---|
| 送信設定ファイル | `%LOCALAPPDATA%\pokenae\BlinkObserverTool\BlinkConfigs\blink-send-configurations.json` | 保存されたキー送信設定一式 |
| プロファイル同期状態ファイル | `%LOCALAPPDATA%\pokenae\BlinkObserverTool\default-profiles-state.json` | 既定プロファイルの同期世代・ハッシュ情報 |
| 認識プロファイル定義 | `%LOCALAPPDATA%\pokenae\BlinkObserverTool\Profiles\<使用プロファイル名>\profile.json` | 認識パラメーターおよび画像定義 |

### インストーラー実行エラー時の詳細ログ取得方法

MSI パッケージのインストールやアンインストールが途中で失敗する場合は、Windows PowerShell で以下のコマンドを実行してインストーラーの詳細ログ（`install.log`）を生成し、そのファイルを共有してください。

```powershell
msiexec /i .\BlinkObserverTool.Installer.msi /l*v install.log
```
